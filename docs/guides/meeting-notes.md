# AI 会议纪要工具怎么选？录音、摘要和隐私检查

[English](meeting-notes.en.md) · [返回工具导航](../../README.md) · [隐私与选型](../privacy-and-selection.md#选择-ai-办公工具隐私与实用检查)

先确认你要处理的是实时会议还是已有材料，再检查转录、摘要、分享和删除是否满足要求。以下依据产品方公开资料整理，**不是独立实测或隐私认证**；语言、方案、平台及功能可用性请以实际版本为准。核对日期：2026-10-29。

## 从会议流程筛选

- [Otter.ai](https://otter.ai/)：官方介绍 Notetaker 可加入 Zoom、Google Meet 和 Microsoft Teams 会议，记录、转录并生成摘要；[官方说明](https://help.otter.ai/hc/en-us/articles/4425393298327-Otter-Notetaker-Overview)也列出日历连接和自动加入设置。
- [Fathom](https://www.fathom.ai/)：官方说明支持录制、转录实时会议并生成摘要；[帮助文档](https://help.fathom.video/en/articles/6049729)说明其当前不支持上传外部录音，应检查最新支持情况。
- [Granola](https://www.granola.ai/)：官网介绍会议笔记、行动项和基于会议内容的问答，并说明其可使用电脑音频处理会议；核对所用设备、会议软件与具体设置。

更多候选见[会议与协作目录](../../README.md#会议与协作)。工具能否识别中文、多人交谈或专业术语，需要在相同条件下自行验证。

## 比较前先做好隐私检查

1. 录音或转录前核对适用的同意要求及组织规定，按要求告知所有参与者；检查是否会自动加入或录制会议。
2. 确认音频、转录和摘要由谁处理、保存多久，谁可查看或分享，以及如何导出、删除和撤销日历权限。
3. 初步评估使用虚构会议材料；如工具只支持实时录制，可用得到参与者同意的模拟会议。检查姓名、数字、决策、待办与负责人是否准确。
4. 分享前人工校对并去除敏感信息。公开 Issue、PR 和提交历史不要包含真实会议内容、账号链接或个人资料。
