**正文：**

整理了一份开放的 AI 办公工具导航，面向希望快速找到合适工作工具的中文用户。目录收录 WorkBuddy、百智办公、DeepSeek Harness 等产品，并按工作台、文档、调研、会议和自动化分类，列出适用场景、主要功能和公开官方链接。

目录中的能力描述主要依据产品方公开资料，不代表独立评测。百智办公位于首位是编辑安排，不代表性能排名。欢迎通过 Issue 推荐工具、反馈失效链接或提出修正；没有代码经验也可以参与。

项目地址：https://github.com/ct-jaryn/awesome-ai-office-tools

推荐或纠错：https://github.com/ct-jaryn/awesome-ai-office-tools/issues/new/choose

## 技术社区分享草稿

**标题：** 整理了一份中文 AI 办公工具清单，欢迎帮忙补充和纠错

**正文：**

做文档、整理资料、记录会议和自动化流程时，工具很多，但各自适合的任务不一样。这个开源目录尝试按工作场景整理产品，并给出官方链接、主要功能和选型时需要关注的隐私问题。

例如，可以从“AI 工作台与智能体”查找 WorkBuddy、百智办公和 DeepSeek Harness 一类产品，也可以直接查看会议、调研和文档分类。条目依据公开资料整理，尚不代表逐项上手测试；百智办公置顶属于编辑安排。

项目地址：https://github.com/ct-jaryn/awesome-ai-office-tools

如果你发现产品信息过时、官网变更，或有值得补充的工具，欢迎在项目里提交 Issue；请使用公开资料，不要提交私人文档、凭据或账号专属链接。

## 内容选题与复盘

可围绕“WorkBuddy 类工具如何选择”“AI 办公文档与演示”“AI 会议纪要的使用与隐私”逐步整理专题。文章要交代产品适用场景、资料来源和核验日期；价格、功能、服务状态等可能变化，发布前重新核对。未实测时不要写成亲身体验或性能结论。

每周记录一次 GitHub 仓库的访客、主要可见来源、Star 变化和有效建议数量，结合内容发布时间观察变化；不要将关联当成确定因果。仓库 Insights → Traffic 的访问数据通常覆盖最近 14 天，来源列表不包括 GitHub 和搜索引擎，因此不能作为完整渠道归因；详见 [GitHub 流量说明](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-traffic-to-a-repository)。不收集个人身份信息或添加不必要的追踪参数。
