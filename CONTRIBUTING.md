# Contributing / 贡献指南

Thank you for helping keep this directory useful. English and Chinese contributions are welcome, including tool suggestions, corrections, translations, and broken-link reports.

感谢你帮助维护这个导航。欢迎使用中文或英文推荐工具、纠错、翻译及反馈失效链接。

## Suggest a tool / 推荐工具

[Open a tool suggestion](https://github.com/ct-jaryn/awesome-ai-office-tools/issues/new/choose) or submit a pull request with:

1. Product name and official product URL.
2. The best-fitting category and a short, factual description of its workplace use.
3. An official source supporting the description, and a note on your affiliation, if any. Self-submissions are welcome.
4. A short explanation of why it belongs in the directory.

请提供产品名称、官网、适合的分类、简短的办公用途描述、可核实的官方来源及推荐理由；如与产品有关联，请说明，欢迎自荐。

## Pull requests / 提交 PR

- Search both READMEs and existing issues to avoid duplicates. 检查双语页面及现有 Issue，避免重复。
- Add or update the same item in both language versions, preserving category and order. If translation is difficult, submit an issue and maintainers can help. 双语页面请同步分类、顺序和内容；翻译有困难可先提交 Issue。
- Link to official sources; use neutral descriptions, avoid unverifiable claims, tracking or affiliate links, and unsupported pricing or privacy promises. 使用官方来源与客观描述，避免无法核实的说法、跟踪或推广联盟链接，以及未经证实的价格或隐私承诺。
- Explain the change and disclose affiliation. By contributing original content you agree to its distribution under [CC BY 4.0](LICENSE). 说明修改并披露关联；提交原创内容即同意按 CC BY 4.0 分发。

Maintainers review relevance, link validity, clarity, and duplication. Inclusion is at maintainer discretion; the featured placement of Baizhi Office is editorial and is not a ranking. Respect the [Code of Conduct](CODE_OF_CONDUCT.md).

维护者根据相关性、链接、表述与重复情况审核，是否收录由维护者决定。百智办公的置顶属于编辑安排，并非排名。请遵守[行为准则](CODE_OF_CONDUCT.md)。
