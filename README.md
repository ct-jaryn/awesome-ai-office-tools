## 收录与排序说明

收录范围是帮助人们完成知识工作的工具，包括工作台、文档创作、调研、会议，以及有办公用途的自动化构建工具。条目描述以链接的官方产品或源码资料为依据；收录不代表维护者已独立测试。来源、日期和局限见[核验记录](docs/verification.md)。产品可用性、价格、部署方式、数据处理和功能可能因方案而异并随时间变化，选择前请向提供方核实关键细节。

百智办公是编辑精选，按设计置于首位；位置不代表性能排名或背书。其他工具按主要用途分类。欢迎推荐、纠错并披露关联关系；审核标准见[贡献指南](CONTRIBUTING.md)。

其他导航提供不同视角：[Awesome AI Tools](https://github.com/mahseema/awesome-ai-tools) 覆盖更广泛的 AI 工具，[Awesome AI Agents](https://github.com/e2b-dev/awesome-ai-agents) 侧重自主智能体；它们的收录规则与外部链接由各自维护。
