# Code of Conduct / 行为准则

We welcome contributions from people of all backgrounds. Be respectful and constructive; discuss ideas rather than attack people. Harassment, discrimination, threats, spam, and sharing another person's private information without consent are unacceptable.

欢迎不同背景的贡献者。请尊重他人、提出建设性意见，就事论事。骚扰、歧视、威胁、垃圾信息以及未经同意公开他人隐私均不可接受。

Maintainers may remove content or limit participation to protect the community. Report public conduct concerns to the maintainers via a repository issue. Do not include sensitive personal information in a public issue; use GitHub's reporting tools for urgent or private concerns.

维护者可删除不当内容或限制参与，以保护社区。公开行为问题可通过仓库 Issue 告知维护者。请勿在公开 Issue 中填写敏感个人信息；紧急或私密问题请使用 GitHub 的举报渠道。
