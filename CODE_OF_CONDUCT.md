# Code of Conduct / 行为准则

We welcome contributions from people of all backgrounds. Be respectful and constructive; discuss ideas rather than attack people. Harassment, discrimination, threats, spam, and sharing another person's private information without consent are unacceptable.

欢迎不同背景的贡献者。请尊重他人、提出建设性意见，就事论事。骚扰、歧视、威胁、垃圾信息以及未经同意公开他人隐私均不可接受。

Maintainers may remove content or limit participation to protect the community. You can raise a public conduct concern in a repository issue. Issues and comments are public: never include private information, credentials, or confidential materials. For content that requires a private report, use GitHub's reporting tools rather than posting the details publicly; those tools report to GitHub, not necessarily to the repository maintainers.

维护者可删除不当内容或限制参与，以保护社区。公开行为问题可通过仓库 Issue 提出。Issue 和评论是公开的：请勿包含隐私信息、凭据或机密材料。需要私下举报的内容请使用 GitHub 的举报工具，不要公开发布详情；这些工具将信息发送给 GitHub，并不一定发送给仓库维护者。
