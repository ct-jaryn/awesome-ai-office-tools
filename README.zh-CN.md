## AI 工作台与智能体

| 工具 | 用途 |
| --- | --- |
| [百智办公 · MonkeyAI](https://work.baizhi.cloud/) · [源码](https://github.com/chaitin/MonkeyCode) | 面向团队的开源 AI 工作台，覆盖办公、编程与设计任务，支持团队管理和独立部署。 |
| [腾讯 WorkBuddy](https://cloud.tencent.com/product/workbuddy) | 覆盖办公、编程和创意工作的 AI 工作台。 |
| [Claude Cowork](https://claude.com/product/cowork) | 可围绕文件和已连接应用处理多步骤任务的桌面 AI 助手。 |
| [ChatGPT](https://chatgpt.com/) | 用于写作、调研、分析等日常任务的 AI 助手。 |
| [Microsoft 365 Copilot](https://www.microsoft.com/en-us/microsoft-365/copilot) | 在 Microsoft 365 应用和工作内容中提供 AI 辅助。 |
| [Gemini for Google Workspace](https://workspace.google.com/solutions/ai/) | 在 Gmail、Docs、Sheets、Slides 等 Workspace 应用中提供 AI 辅助。 |
| [Manus](https://manus.im/) | 用于调研及其他多步骤任务的 AI 智能体。 |
| [Octop](https://github.com/TencentCloud/Octop) | 支持多用户和多智能体的自托管 AI 助手。 |
| [OpenClaw](https://github.com/openclaw/openclaw) | 可连接消息渠道和工具的个人 AI 助手。 |
